How it works

  • The model extracts facts into the master schema. If it fails, the built-in text parser is used.
  • Merge adds new items and fills gaps without duplicating existing ones.
  • Replace discards the current master and writes only what was imported.
  • Files stay in {{ resumes_dir }}; they are not modified or uploaded anywhere except your configured model.

Safety

  • Preview first; nothing is written until the preview is confirmed.
  • Every write backs up the previous master.yaml to data/backups/.
  • Only files listed in the resumes/ folder can be selected.
  • Import one person's resumes at a time.
